# 🎲 Roll a Ball 3D Game

A modern, 3D physics-based arcade game developed using the Unity Engine and programmed in C#.

---

## 👥 Project Type
* **Individual Project**

---

## 🛠️ Tech Stack & Technologies Used

* **Game Engine:** Unity (3D) - Unity 6.5
* **Programming Language:** C#
* **Physics & Mechanics:** Unity Rigidbody, Collider Systems
* **Version Control:** Git & GitHub

---

## ✨ Key Features & Gameplay

### 🎮 Player Movement & Physics
* Smooth 3D ball movement and physics controls utilizing Unity's Rigidbody component.
* Responsive keyboard inputs for navigating through dynamic 3D environments.

### 📷 Camera Mechanics
* Dynamic camera follow system to seamlessly track the player across the map.

### 🏆 Collectible & Scoring System
* Interactive collectible items scattered throughout the level.
* Real-time score tracking and updates upon item collection.

---

## 🗄️ Project Structure & Scenes

The project is structured within the standard Unity directory format:
* `Assets/Scenes` : Contains the main game scenes.
* `Assets/Scripts` : Houses all modular C# scripts for player controls, camera behavior, and score management.
* `Assets/Materials & Prefabs` : Stores visual materials, colors, and reusable game objects.
